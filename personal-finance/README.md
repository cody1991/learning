# 个人理财常识

目标：**先把钱的基本盘理顺**——预算、应急金、债务、长期投资原则；在荷兰生活时能看懂常见机构说明。  
不是：短线炒股、币圈信号、复杂保险推销课。

## 进度

- [ ] 列出每月固定收支，定一个简单预算（可用 Nibud 工具/文章）
- [ ] 设好应急金目标（先定月数，再执行自动转账）
- [ ] 读完 Bogleheads Getting started（或等价笔记）
- [ ] 读完《The Psychology of Money》
- [ ] 能用自己的话解释：应急金 / 指数化长期持有 / 为何不追热点
- [ ] （可选）弄清自己账户的养老金/社保条目在哪看
