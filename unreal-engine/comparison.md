# 为什么只推这一门课 + 官方

## 选择标准

你说了：题材不限，**质量高就好**。因此不按「射击/工具」拆路线，只按质量与可维护性筛。

## 主课：Ulibarri UE5 C++ Ultimate

| 优点 | 说明 |
|------|------|
| C++ 主线完整 | Actor、Component、碰撞、UI、AI、存档等一条龙 |
| 社区与配套仓活跃 | 有 GitHub 课仓可对照 |
| 少依赖「纯蓝图思维」 | 适合继续用 AI 写代码，而不是拖节点 |

瑕疵：录制版本通常不是最新点的 5.8 → **用 5.8 建工程 + 官方文档补差** 即可，不必等「5.8 重录版」。

## 官方：5.8 文档 + Sample

| 资源 | 链接入口 |
|------|----------|
| 5.8 Release Notes | https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-5-8-release-notes |
| Programming with C++ | https://dev.epicgames.com/documentation/en-us/unreal-engine/programming-with-cplusplus-in-unreal-engine |
| Epic Learning | https://dev.epicgames.com/community/unreal-engine/learning |
| Lyra Starter Game 等 | Epic Launcher → Samples / Fab（以当前 Launcher 为准） |

Lyra 不是「跟练教程」，是**看正规项目怎么拆模块**；卡架构时翻，不必从头抄。

## 高质量备选（主课不够或想加餐时）

| 资源 | 何时看 |
|------|--------|
| [Tom Looman](https://tomlooman.com/) / Action Roguelike 课与文章 | 主课结束后想看更偏实战/架构 |
| Epic 官方 Learn 里高赞 **C++** 专题 | GAS、网络、UI 等主课没覆盖的点 |
| 中文长课（原子之音等） | 仅当英语听课吃力时作对照；版本往往更旧 |

## 不优先

- 纯蓝图入门长课（和 C++ / AI 协作目标相反）
- 同时开 3～4 门「从零 UE」→ 质量再高也稀释
- 只追 B 站最新 5.8 合集、作者不维护的 → 质量不稳
