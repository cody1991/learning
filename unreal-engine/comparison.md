# 为什么这样推荐（含企业 Udemy 约束）

## 选择标准

质量优先 + **企业 Udemy 可能没有 Ulibarri** → 默认 **免费官方路径**；有企业课再替换视频跟练部分。

## 路径 A：免费官方（当前默认）

| 资源 | 链接 | 角色 |
|------|------|------|
| C++ Quick Start | https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-cpp-quick-start | 第一天动手 |
| Programming with C++ | https://dev.epicgames.com/documentation/en-us/unreal-engine/programming-with-cplusplus-in-unreal-engine | 系统文档 |
| 5.8 Release Notes | https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-5-8-release-notes | 版本差 |
| Epic Learning | https://dev.epicgames.com/community/unreal-engine/learning | 免费视频/专题 |
| Lyra | https://dev.epicgames.com/community/learning/courses/Yj3/unreal-engine-lyra-sample-game | 正规项目结构 |

优点：对齐 **5.8**、免费、和引擎同源。  
缺点：不如一门商业课「一条龙带项目」那么省心，要自己串。

## 路径 B：Ulibarri 系统课（企业库有或自费时）

- 课：https://www.udemy.com/course/unreal-engine-5-the-ultimate-game-developer-course/
- 代码：https://github.com/DruidMech/UE5_TheUltimateDeveloperCourse  

仍是质量最高的「一课打通」选项之一；课页约到 **5.7**，本地用 5.8 + 文档补差。

## 路径 C：企业库里的其它 C++ 课

在 https://tencent.udemy.com/ 按 [enterprise-udemy.md](./enterprise-udemy.md) 搜。  
质量参差 → 用「有 C++ 大纲」筛选；找到后可当路径 A 的视频补充，或临时主课。

同作者其它常见公开课（企业库不一定有）：

- Multiplayer Shooter（C++）：https://www.udemy.com/course/unreal-engine-5-cpp-multiplayer-shooter/  
  （偏联机，入门负担更大，有基础再看）

## 其它高质量但通常也收费 / 不在企业 Udemy

| 资源 | 链接 | 说明 |
|------|------|------|
| Tom Looman C++ 学习路径 | https://tomlooman.com/courses/unrealengine-cpp/ | 质量高，独立站收费，一般不在 tencent.udemy |
| ActionRoguelike 示例仓 | https://github.com/tomlooman/ActionRoguelike | 可免费读代码 |
| Tom Looman 博客 | https://tomlooman.com/ | 免费文章 |

## 不优先

- 纯蓝图长课  
- 同时开很多「从零 UE」  
- 只为「有课可看」选企业库里的蓝图课当主线
