## 挑选标准（质量门槛）

| 要 | 不要当主课 |
|----|------------|
| 大纲有 **C++ 跟练项目**（不是概念扫盲） | 只有 Blueprint / 蓝图 |
| 讲师有口碑或评分数千级且差评不指向「念稿/AI」 | 「Complete Guide / Zero to Hero」百科式超长课 |
| Character、GAS、Enhanced Input 等可验证章节 | 只教关卡美术、过场 |
| 近 2–3 年有更新更佳 | UE4 老课且从不提 UE5 |

**在库 ≠ 推荐。** 先看大纲深度与低分评，再决定是否跟练。

## 质检笔记（2026-08-04）

| 课名 | 企业站链接 | 结论 |
|------|------------|------|
| Ulibarri Ultimate Game Developer | https://tencent.udemy.com/organization/course-not-available/4720022/ | **不在库**（页面明示不包含） |
| The C++ Arsenal（Neville Adams） | https://tencent.udemy.com/course/cpparsenal/ | **不推荐作 UE 主课**。约 4.6 / 310 评；~70h 大半是 C++101 零基础；UE 只到 fundamentals + 小游戏。已会编程 → 性价比低，跟官方 C++ Quick Start 更快。 |
| Unreal Engine 5 C++: Advanced Action RPG（Vince Petrelli） | https://tencent.udemy.com/course/unreal-engine-5-advanced-action-rpg/ | **有基础后的企业最佳候选**。约 4.6 / 750+ 评；~44h；GAS、连招、AI、Boss——真·C++ 玩法工程。先走 Epic Quick Start + 文档，再上这门。 |
| Custom Editor Tools / Advanced Frontend UI | 各自课程页 | **专题加餐**，不当入门主线 |
| Complete Beginner’s 等蓝图课 | 搜索页混入 | **不当主线** |
