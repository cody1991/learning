# 企业 Udemy（tencent.udemy.com）怎么找课

企业目录 **≠** 公开 https://www.udemy.com/ 全量。搜不到 Ulibarri 很常见，不一定是账号坏了。

## 建议搜索词（复制到企业站搜）

优先带 **C++**（避开纯蓝图）：

- `Unreal Engine 5 C++`
- `Unreal C++`
- `UE5 C++`
- `Unreal Engine Multiplayer`（很多是 C++，看简介）
- `GameDev.tv Unreal`（部分企业会进 GameDev.tv 课）
- 讲师名：`Stephen Ulibarri` / `Druid Mechanics`（有时同作者别的课在库里）

## 挑选标准

| 要 | 不要当主课 |
|----|------------|
| 标题/大纲明确 **C++** | 只有 Blueprint / 蓝图 |
| 有 Character、Component、Enhanced Input 等 | 只教关卡美术、过场 |
| 近 2–3 年有更新说明更佳 | UE4 老课且从不提 UE5（可当概念参考，别当唯一路径） |

找到候选后：打开大纲确认有 `.h/.cpp` / Visual Studio，再决定是否替换「官方主线」里的视频部分。

## 仍没有合适课时

1. 走本目录的 **免费官方主线**（README 最短清单）  
2. 走内部流程 **申请把课加入 Udemy Business 目录**（很多企业支持 request content；把公开课链接交给管理员）  
   公开课链接：https://www.udemy.com/course/unreal-engine-5-the-ultimate-game-developer-course/  
3. 中文免费长视频可作对照（版本偏旧，工程仍用 5.8）：  
   - https://www.bilibili.com/video/BV1af421R7BD （原子之音 UE5.4 C++）  
   - https://www.bilibili.com/video/BV1uGEt6CECx （设计门外憨 UE5 C++）
