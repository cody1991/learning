## 2026-08 复搜备注（不落盘否决课）

- 搜「UE5 C++」前列混有：David Nixon / Greg Wondra / Eric Ruts / Unreal magic / Aidan Perry / Skillademia 等——多数大纲是 **蓝图 / 材质 / 生存框架 / ALS 动画**，不对 C++ 主线  
- 非 Vince 且标题带 C++ 的：Neville Adams《C++ Arsenal》偏通用语言大全，不作主线  
- Ulibarri / 若干 GameDev.tv C++ 课：**不在库**  
- 因此企业过关的 **C++ 玩法课**目前仍是 Vince 的 Climbing（短）+ Action RPG（进阶）；不是「只认一个人」，是库里合格选项就这些  
- 已有蓝图 demo 经验只说明编辑器不陌生，可直接开官方 C++ 新工程
