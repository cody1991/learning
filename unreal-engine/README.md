# Unreal Engine（C++）

目标版本：**UE 5.8**；语言：**C++ 为主**（蓝图仅作关卡/调参，少用 AI 改蓝图）。  
题材不限：优先选**质量高、维护好**的教程，不卡第三人称/射击/工具。

## 最短清单（就这两样）

| # | 资源 | 角色 |
|---|------|------|
| 1 | Stephen Ulibarri《**Unreal Engine 5 C++ The Ultimate Developer Course**》（Udemy） | **主课** — 目前口碑最完整的 UE5 C++ 系统课 |
| 2 | Epic 官方文档 **5.8** + 官方 Sample（Lyra 等） | **权威对照** — 课里 API 和 5.8 不一致时查这里 |

配套代码仓（随主课）：https://github.com/DruidMech/UE5_TheUltimateDeveloperCourse  

细节见 [comparison.md](./comparison.md)、[path.md](./path.md)。

## 进度

- [ ] 安装 UE **5.8** + IDE（Windows: VS / Mac: Xcode）
- [ ] 开主课，工程版本对齐 5.8（或课内版本先跟，遇 breaking change 查 5.8 文档）
- [ ] 跑通官方 Sample（建议 Lyra）浏览结构
- [ ] 主课核心段跟完后，自开一个小项目巩固

## 原则

- 教程质量 > 是否「纯 5.8 录制」（多数好课是 5.3–5.5，C++ 框架可迁移）
- 逻辑写 C++；少让 AI 直接改蓝图
- 不同题材都可，跟主课走即可，不必同时开很多课
