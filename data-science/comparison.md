# 为什么这样推荐

## 这条线解决什么

| 要会的 | 不靠这条线 |
|--------|------------|
| 表格数据清洗、探索、可视化 | 仓表调度 / Airflow（DE） |
| 回归/分类、验证、指标 | LLM Prompt / Agent（Microsoft AI） |
| 从 notebook 到可复现实验习惯 | GPU serving / vLLM（AI Infra） |

## 一句话区别

| 资源 | 一句话 |
|------|--------|
| Python Data Science Handbook | 免费在线书，把 NumPy/Pandas 用熟 |
| Google ML Crash Course | 短、官方、把 ML 基本词对齐 |
| ML Zoomcamp | 免费实战营风格，端到端经典 ML |

## 难度 / 模式

| 资源 | 难度 | 模式 |
|------|------|------|
| Handbook | ★★☆ | 在线书 + 代码 |
| Crash Course | ★★☆ | 视频 + 练习 |
| ML Zoomcamp | ★★★ | 视频/笔记 + 作业 |

## 原则

- 先 Pandas 手感，再模型；别一上来只调库参数  
- 主线只要 Zoomcamp 一条实战课；Kaggle 竞赛可后置  
- 不堆付费「数据科学大全」课
