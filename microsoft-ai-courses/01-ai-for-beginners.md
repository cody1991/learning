# AI for Beginners

- 仓库：https://github.com/microsoft/AI-For-Beginners
- 中文：https://github.com/microsoft/AI-For-Beginners/blob/main/translations/zh-CN/README.md

- 体量：12 周，24 课
- 状态：**当前目标下建议跳过**

## 是什么

经典 AI 入门课：符号 AI → 神经网络 → CV → NLP → RL / 伦理。  
双框架（PyTorch + TensorFlow），含 lab、测验、sketchnote。

## 教学模式

- 主：Markdown 教材 + Jupyter Notebook
- 辅：Quiz、Lab
- 几乎没有系统配套讲解视频

## 难度

★★★★ — 三门里最累、最长。后面 CV/NLP 要耐心和代码基础。

## 学什么 / 不学什么

会学：感知器、CNN、RNN、Transformer/BERT、一点 LLM、遗传算法等。  
不覆盖：商业 AI 案例、经典 ML（另有 ML-for-Beginners）、Azure 认知服务、聊天机器人深度、深度数学。

## 和 Agent 目标的关系

偏低。作者也写明前沿模型覆盖偏少；LLM 只有一课。  
若目标是写 Agent 工具 / Skills，时间更好花在 Generative AI + Agents。
