# Microsoft AI 系列课程笔记

面向目标：**Agent 工具 / Skills 开发**。

## 学习顺序（当前计划）

一门门来，建议顺序：

1. ~~AI for Beginners~~ — **跳过**（偏经典 AI/深度学习原理，与 Agent 目标不对口）  
   仓：https://github.com/microsoft/AI-For-Beginners
2. [Generative AI for Beginners](./02-generative-ai-for-beginners.md) — 先扫盲 Prompt / Function Calling / RAG  
   仓：https://github.com/microsoft/generative-ai-for-beginners
3. [AI Agents for Beginners](./03-ai-agents-for-beginners.md) — 主线，Tool Use / Planning / MCP 等  
   仓：https://github.com/microsoft/ai-agents-for-beginners
4. （可选）[MCP for Beginners](https://github.com/microsoft/mcp-for-beginners) — 专门做工具协议时再看

详细对比见 [comparison.md](./comparison.md)。
