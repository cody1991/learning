# 为什么这样推荐

## 目标意味着什么

| 目标 | 对策 |
|------|------|
| 荷兰生活能办事 | 优先口语/听力常用场景，不先刷文学 |
| 时间有限 | 短视频主线 + 语法当字典 |
| 英语已能支撑工作 | 荷语是加分/生活，不和英语线抢同一练习方式硬比 |

## 一句话区别

| 资源 | 一句话 |
|------|--------|
| learndutch.org | 免费主题视频，适合零基础入门跟练 |
| dutchgrammar.com | 系统语法站，卡规则时查 |
| 生活输入 | 把环境里的荷语变成可回放的学习材料 |

## 难度 / 模式

| 资源 | 难度 | 模式 |
|------|------|------|
| learndutch.org | ★★☆ | 视频 + 练习页 |
| dutchgrammar.com | ★★☆ | 文档查阅 |
| 生活输入 | ★★★ | 真实语速，需文稿/翻译辅助 |

## 原则（不堆课）

- 先 1 条视频主线，再加打卡 App；不要同时开 3 个 App  
- 暂不把「冲 NT2 证书」当第一目标；生活句稳了再评估考试路径  
- 不与英语线互相链进度；两条独立
