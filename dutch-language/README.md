# 荷兰语（生活向）

场景：人在荷兰，日常以英语也能过，但办事 / 邻里 / 标牌常碰到荷兰语。  
目标：**先能听懂慢速生活用语、会说常用句**；不冲考试级 NT2 全科（需要时再开）。

## 最短清单

| # | 资源 | 链接 | 角色 |
|---|------|------|------|
| 1 | Learn Dutch with Bart | https://www.learndutch.org/ | **主线视频**（免费、按主题） |
| 2 | Dutch Grammar | https://www.dutchgrammar.com/ | **语法索引**（查用，不线性读完） |
| 3 | 生活输入 | 超市/车站播报、信件、App 荷语界面 | **半主动**（每天顺带） |

可选加餐（习惯稳后再加）：[Clozemaster Dutch](https://www.clozemaster.com/languages/d/dutch) 或 Anki 高频词；市级免费 NT2 课（本地 gemeente / 图书馆查）。

详细对比见 [comparison.md](./comparison.md)；每日练法见 [routine.md](./routine.md)。

## 进度

- [ ] 装好 / 收藏 learndutch.org，定每天 15–20 分钟
- [ ] 连续 2 周：每天 1 小节视频 + 跟读关键词句
- [ ] 能独立说清：自我介绍、问路、点餐、约时间
- [ ] 碰到信件/表格：能用词典抠出「要我做什么」
- [ ] （可选）报名本地入门荷语课或语伴
