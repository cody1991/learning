# 英语口语 / 听力

在荷兰生活场景：能接触英语，但经常听不清、也不爱主动说。  
目标：先听懂日常语速 → 私下敢开口 → 再慢慢用真实对话。

## 定位（当前）

- 水平：一般
- 听力：真实对话/快速语流经常跟丢
- 口语：回避开口（优先降低心理门槛，不硬上高强度外教）

## 只保留 3 个主力（先做到这三件）

| # | 资源 | 做什么 | 频率 |
|---|------|--------|------|
| 1 | [BBC 6 Minute English](https://www.bbc.co.uk/learningenglish/english/features/6-minute-english) | 听 + 看文稿复查 + **影子跟读** | 每天 15–20 分钟 |
| 2 | 生活里「半主动」听力 | 荷语环境里的英语：播客/视频开英字；超市/办事可听员工英语 | 每天顺带 |
| 3 | [Speechling](https://speechling.com/) 或手机录音跟读 | **独处开口**，不社交也能练说 | 每天 10 分钟 |

外教（italki 等）**先不作为主力**；等跟读不再尴尬后，再加每周 1 次短课。

详细对比与荷兰场景技巧见 [comparison.md](./comparison.md) / [routine.md](./routine.md)。

- [ ] 开始 Speechling / 自录跟读
- [ ] （可选）加每周 1×25 分钟外教或语伴
