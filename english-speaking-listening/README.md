# 英语口语 / 听力

场景：荷兰生活，日常能接触英语。  
目标：听懂接近自然语速 → 跟读/自练开口 → 再进入真实对话。

## 定位（当前）

- 水平：一般
- 听力：真实对话 / 快速语流还需文稿辅助
- 口语：以跟读、自录为主；外教后置

## 只保留 3 个主力（先做到这三件）

| # | 资源 | 做什么 | 频率 |
|---|------|--------|------|
| 1 | [BBC 6 Minute English](https://www.bbc.co.uk/learningenglish/english/features/6-minute-english) | 听 + 看文稿复查 + **影子跟读** | 每天 15–20 分钟 |
| 2 | 生活里「半主动」听力 | 播客/视频开英字；办事等场合留意英语 | 每天顺带 |
| 3 | [Speechling](https://speechling.com/) 或手机录音跟读 | 跟读与自录对比 | 每天 10 分钟 |

外教（italki 等）**先不作为主力**；跟读习惯稳定后，再加每周 1 次短课。

详细对比见 [comparison.md](./comparison.md) / [routine.md](./routine.md)。

## 进度

- [ ] 连续 2 周：每天 6 Minute + 跟读

- [ ] 开始 Speechling / 自录跟读
- [ ] （可选）加每周 1×25 分钟外教或语伴
